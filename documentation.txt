PROJECT TITLE : MINISHELL
--------------------------------------------------------------------------------------------------------------------------------------------
PROJECT INFO : 
-> Mini Shell is a simple commmand-line interpreter to demonstrate the basic concepts of operating systems and Linux process management.
-> The shell accepts commands from the user, identifies whether they are built-in or external commands, and executes them accordingly. 
-> It also supports process control features such as pipes, foreground/background execution, signals, and stopped-job management.

-> The main objective of this project is to implement a basic Linux shell uisng C.
-> To understand and use the system calls w.r.t process creation, signal handling, process synchronization, exit status, text parsing etc..
-> In this project, execution of Internal and external commands can be done and also it implements inter process communication using pipes.
-> Signal handling such as SIGINT, SIGTSTP, and SIGCHLD along with basic job control using jobs, fg, bg. 

--------------------------------------------------------------------------------------------------------------------------------------------
